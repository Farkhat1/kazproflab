# КазПроф Лаб

Самостоятельный сайт по выбранному макету `../output/design-concepts-round-3/03-technological.png`.
Перенесены 59 исходных адресов: главная, 6 общих страниц, 19 категорий и 33 услуги.

## Посмотреть сайт

Локальная готовая сборка: <http://127.0.0.1:4174>.

Чтобы открыть её позже, запустите `Open website.cmd` в основной папке проекта. Он запускает локальный сервер и открывает браузер. Публикация в интернете и изменение домена при этом не выполняются.

## Что работает

- Адаптивная главная и все внутренние страницы.
- Каталог, поиск по названиям, стандартам и описаниям, фильтры по направлениям.
- Полные описания, изображения, цены, характеристики курсов и контакты.
- Кнопка WhatsApp слева: `77004496383`, с адресом текущей страницы в сообщении.
- Форма консультации готовит черновик в WhatsApp. Пользователь отправляет его самостоятельно; почтового сервера и базы заявок нет.
- Все исходные URL, HTML с содержимым, индивидуальные метаданные, sitemap, реальные 404 на статическом хостинге.

## Разработка

Node.js 22+, npm. На Windows для генерации HTML используется установленный Microsoft Edge. На другой системе установите Chromium: `npx playwright install chromium`.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`build` включает Vite, подготовку совместимого пакета Sites и генерацию 59 HTML-страниц. Для обычного хостинга используется только `dist/client`, включая скрытый `.htaccess`. Конфигурация Nginx и инструкция — в `deploy/`.

Данные: `src/data/site-data.json`, структурированная главная: `src/data/home-content.json`. При редактировании данных выполните сборку заново. Содержимое и оформление отделены друг от друга.

Исходные HTML и аудит сохранены в `../content-source`. `npm run content:sync` повторно переносит этот снимок и оптимизирует исходные изображения в WebP; команда перезаписывает `src/data` и требует соседние папки `content-source` и `content-assets`. Обычная сборка в них не нуждается.

## Проверки

При работающем preview браузерные проверки запускаются так:

```powershell
$env:BASE_URL = 'http://127.0.0.1:4174'
$env:EXPECT_PRERENDER = '1'
npm run test:browser
npm run test:sites
```

Браузерный сценарий проверяет все маршруты, сохранность текстов, цены, ссылки, изображения, адаптивность, поиск, фильтры, меню и консультации. WhatsApp перехватывается в тесте, сообщения не отправляются. Результат финального прогона: `qa/production/browser-report.json`. Визуальное сравнение: `qa/comparison.png`; вывод: `design-qa.md`.

Перед публикацией владелец должен проверить несколько противоречий исходного контента: `../content-source/REVIEW-NOTES.md`. В частности, SAPA SPACE / Алматы и разная длительность одного курса. Содержательные условия не были произвольно переписаны.
